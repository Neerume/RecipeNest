RecipeNest

RecipeNest is a simple full-stack recipe web app where users can explore, create, and manage their favorite recipes. It’s built to make cooking ideas easy to save and share.

## Features
- Sign up / Login system
- Add, edit, and delete recipes
- Browse and search recipes
- Clean and responsive UI
- Can like and comment on recipe
- Can view previously liked recipes

Tech Stack
- React
- Node.js + Express
- MongoDB
- JWT Authentication

Setup 
git clone https://github.com/Neerume/Recipenest.git
cd Recipenest

Frontend
cd client
npm install
npm start

Backend
cd server
npm install
npm start

# Note #
Create a .env file in the server folder with your MongoDB URI and JWT secret before running the project.
